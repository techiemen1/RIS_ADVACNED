# RIS-iPACX: Dashboard (Workspace)

The Dashboard is the operational hub for clinical workflows, providing real-time visibility into the department's status.

## 1. Real-time Scheduling & Worklist
- **Dynamic Filtering**: Staff can filter studies by Date, Modality, and Patient Status (Pending, Completed, Draft).
- **Auto-Sync**: The worklist periodically polls the PACS and Local Database to reflect newly arrived scans.

## 2. Modality-specific Workflow
- **Visual Color Coding**: Each modality (CT, MR, XR) is assigned a custom color for quick visual identification.
- **MWL Server Integration**: Scheduled patients are automatically pushed to the Modality Worklist (MWL) for imaging acquisition.

## 3. Integrated Analytics
- **Volume Metrics**: Real-time counters show the number of studies performed per modality.
- **Reporting Efficiency**: Tracks the time elapsed between scan acquisition and report finalization.
