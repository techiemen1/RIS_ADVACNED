# RIS-iPACX: User Operational Guide

This guide is intended for Radiologists, Technicians, and Hospital Staff using the RIS-iPACX platform for daily operations.

## 1. Patient Registration & Worklist
- **Registration**: Capture patient demographics and assign modalities.
- **Worklist**: Real-time status tracking of all imaging studies. Use filters to find pending or completed cases.

## 2. Integrated PACS Explorer
- **Image Retrieval**: View images directly from the worklist using the integrated OHIF selector.
- **Study Comparison**: Open multiple series side-by-side for comparative diagnosis.

## 3. Professional Report Editor
- **Whisper Neural Dictation**: High-fidelity AI speech-to-text. Click 'Start Neural Dictation' and speak clinical findings directly into the editor.
- **Smart Templates**: Rapidly insert standardized report structures based on the study type.
- **Key Image Insertion**: Seamlessly attach critical images from the PACS directly into the diagnostic report.

## 4. Finalization & Distribution
- **Drafts**: Save progress at any time.
- **Verification**: Once satisfied, 'Finalize' the report to freeze the content and prepare for printing.
- **Secure Shared Link**: Generate a mobile-friendly link and OTP code for patients to access their reports securely via the Patient Portal.
- **Pay-per-View (Patient)**: Patients can securely pay for diagnostic reports via UPI/Credit Card using the integrated Razorpay checkout.
- **Smart Delivery (WhatsApp/SMS/Mail)**: After finalization, click 'Deliver Report' to send the access link and OTP directly to the patient's phone or email. This eliminates manual coordination and improves patient satisfaction.
